# Student Management System

A simple Student Management System built using:

- C++
- MySQL
- MySQL C API

## Features

### Admin Portal
- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student
- Branch-wise Student Ranking

### Student Portal
- Login using Scholar ID
- View own CGPA and Branch
- View branch-wise CGPA ranking

## Database

MySQL database used:

`student_management`

Tables:

- Students
- Admins
